TrueSign: The Anti-AI Camera (Android Beta)

Hardware-backed cryptographic proof for the deepfake era.

TrueSign is an open-source camera app that uses the Android Secure Enclave (Hardware Keystore) to cryptographically sign photos at the moment of capture. It creates a chain of custody from the physical sensor to the cloud, proving an image was not generated by AI or edited in Photoshop.

🌐 Verify a Proof / Download APK: truesign-web.vercel.app

Architecture: The "Closed Loop"

TrueSign is not a file editor. It is a camera. It rejects any image that does not originate from the hardware sensor buffer.

Security Model

Key Generation: Upon installation, the app triggers the Android Keystore to generate an ECC (Elliptic Curve) Key Pair inside the Trusted Execution Environment (TEE).

Attestation: The private key is flagged as Non-Exportable. It physically cannot leave the device hardware.

Signing: When the shutter is pressed, the pixel data is hashed and sent to the TEE. The TEE returns a signature.

Verification: The web portal uses the Public Key to verify the signature against the image data.

Constraints & The "Analog Hole"

We value transparency over hype. Here is what TrueSign cannot stop:

The Analog Hole: You can take a photo of a computer screen showing an AI image. TrueSign will sign it because it is technically a "real photo of a screen." However, metadata (focus distance, lighting) and Moiré patterns usually reveal this.

Rooted Devices: While we use hardware attestation, a highly sophisticated attacker with kernel-level root access could theoretically spoof the sensor driver.

🛠 Tech Stack

Mobile: React Native (Expo) + Kotlin (Native Modules)

Crypto: AndroidKeyStore API (ECDSA P-256)

Backend: Supabase (PostgreSQL + Storage)

Web: Next.js + Tailwind CSS
